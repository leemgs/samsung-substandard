⚙️ 설정

키워드를 GitHub 저장소에 바로 저장하기 위한 연결 정보를 등록합니다.

GitHub 저장소 연결

GitHub fine-grained 토큰(이 저장소 한정, Contents: Read and write 권한)을 입력하면 [관심 키워드] 페이지에서 저장소에 바로 반영됩니다.

보안 안내

  • 토큰은 이 브라우저(localStorage)에만 저장되며 서버로 전송되지 않습니다. GitHub API 호출에만 사용됩니다.
  • 토큰은 이 저장소 하나, Contents 권한만 주세요. 다른 권한은 필요하지 않습니다.
  • 공용 PC에서는 사용 후 반드시 토큰 삭제를 누르세요.
  • 토큰이 유출되었다면 GitHub → Settings → Developer settings 에서 즉시 폐기하세요.

토큰이 없다면

토큰 없이도 관심 키워드 페이지의 keywords.json 다운로드로 파일을 받아 저장소의 docs/data/keywords.json에 직접 커밋할 수 있습니다.
