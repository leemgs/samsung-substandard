다음 자동 확인 예정

  1. 계산 중…

GitHub 예약 실행은 부하에 따라 몇 분~수십 분 늦거나 드물게 건너뛸 수 있습니다. 위 시각은 예정 시각입니다.

동작 방식

  1. GitHub Actions가 등외급몰에 로그인하고 등록된 카테고리(현재 세탁건조기·모니터·에어컨)의 목록을 읽습니다. (“더보기”도 끝까지)
  2. 등록한 관심 키워드와 일치하는 물품을 찾습니다. 키워드는 물품명과 카테고리명 모두에 대해 검사합니다.
  3. 이전에 알린 적 없는 새 물품만 골라 Gmail로 보냅니다. 같은 물품은 다시 알리지 않습니다.
  4. 결과는 확인 결과 페이지에 갱신됩니다. 새 물품에는 NEW 표시가 붙습니다.

문제 해결

메일이 오지 않아요

① 스팸함을 확인하세요. ② 관심 키워드가 등록·저장되어 있는지 확인하세요. ③ 이미 알린 물품은 다시 오지 않습니다. ④ 홈의 “마지막 확인”이 오래됐다면 아래 “수동 실행”을 사용하세요.

“마지막 확인”이 오래됐어요 / 자동 확인이 안 돌았어요

GitHub 예약 실행이 지연되거나 건너뛰었을 수 있습니다. 아래 방법으로 직접 실행하면 즉시 확인합니다.

수동으로 실행하려면?
  1. Actions → Familynet Alert 를 엽니다.
  2. Run workflow → 브랜치 main → 옵션은 모두 비워 둔 채 실행합니다. (dry_run을 체크하면 메일 없이 결과만 확인합니다.)
  3. 약 1분 뒤 완료되며, 새 물품이 있으면 메일이 발송됩니다.

⚠️ 화요일 00:00~12:00(KST)에는 사이트가 로그인을 막아 실행이 실패합니다. 12시 이후에 실행하세요.

화요일 오전에 실행했더니 실패해요

정상입니다. 등재 시간에는 등외급몰이 로그인을 차단합니다. 알리미는 이 경우 “등재 시간에는 로그인을 막고 있습니다”라는 메시지와 함께 실패하며, 계정 정보는 전송하지 않습니다.
